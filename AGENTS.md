# Writing

Use [ASD-STE100 Simplified Technical English, Issue 9](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) for all project text.
This includes replies, interface text, tutorials, documentation, reports, and code comments.

- Use the approved dictionary words with their approved meanings and parts of speech.
- Use technical names and technical verbs only as the standard permits.
- Define a new technical term when you first use it.
- Use the same term for the same item or action.
- Use active sentences and simple verb forms.
- Give each instruction in the command form.
- Put one instruction in each sentence, unless the actions must occur together.
- Limit procedure sentences to 20 words and descriptive sentences to 25 words.
- Keep each paragraph on one topic, with no more than six sentences.
- Give necessary conditions before the related instruction.
- Keep necessary articles and connecting words. Do not use contractions.
- Give information in a logical sequence. Remove text that does not help the reader.
- Preserve scientific meaning, equations, units, identifiers, source titles, quotations, licenses, and historical evidence.
- Before publication, do a check against the complete rules and dictionary.
- Do not claim compliance from sentence length alone.

This summary does not replace the standard or establish compliance of existing text.
