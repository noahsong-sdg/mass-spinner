# Neutral Ar collision data attribution

Ar–Ar Q11/Q22 values in transport-data.json and Q22 in
src/fuel-neutral-transport.ts are transcribed from Mutation++v1.0.5,
data/transport/collisions.xml, ref Wright2005, DOI10.2514/1.16713.
Source: https://github.com/mutationpp/Mutationpp/tree/v1.0.5

Mutation++ copyright2014–2020 von Karman Institute for Fluid Dynamics;
LGPL-3.0-or-later. The original COPYING and COPYING.LESSER texts and pinned
XML/source hashes are retained with the scientific source-data artifacts.
This project adds strict range rejection and evaluates its own first-order
monatomic Chapman–Enskog formulas. It does not claim a full Mutation++ solver
run or reproduce a plasma-mixture database by using this neutral pair table.

Li transport fit: Moncef Bouledroua, J. Plasma Fusion Res. SERIES7(2006)217–219.
No measured plasma-mixture uncertainty is provided by that theoretical fit.
