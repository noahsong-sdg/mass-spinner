# Text review · 19 November 2026

## Scope

This review applies ASD-STE100 Issue 9 to the maintained tutorials, documentation pages, and interface text.
It includes controls, diagrams, component descriptions, calculation limits, and runtime messages.
The review used the official rules and dictionary, including approved meanings and parts of speech.
Sentence length alone is not proof of compliance. This review is not formal STE certification.

The source includes Markdown, HTML templates, TypeScript text, and two display catalogs.
`scripts/build.mjs` makes the published pages from these sources.
The interface also displays assumption and error strings from calculation modules.

Historical studies, raw results, measured values, source titles, quotations, and licenses keep their original text.
Embedded GLB provenance also stays unchanged. A text review does not qualify a changed binary asset.
Identifiers and the three assumption prefixes used by thermal filters stay unchanged.

## Problem and cause

Long sentences combined instructions, equations, and model limits.
Some explanations introduced a calculation before its purpose.
The same concept also had different names in the guide and interface.

The text comes from several source paths. A Markdown-only change would leave much of the interface unchanged.
In simple terms, the reader received different explanations of the same result.

## Changes

The tutorials now start with the result that the reader wants to understand.
Each new equation supplies information necessary for that result.
Instructions use short command sentences. Labels and diagram instructions use the same terms.
Technical terms keep their scientific meanings.

The change keeps the calculation and control paths.
This is smaller than a new documentation system or a change to the simulator architecture.

The physics review also found these wording problems:

- A larger mass gives a larger wall-to-axis equilibrium density ratio, not always a larger absolute density derivative.
- Separation trends must identify constant temperature or constant rotation speed.
- A prescribed field excludes plasma feedback on that field. It does not exclude particle motion in the field.
- Pure feeds keep their composition. The heavy/light ratio definition of separation factor uses a mixed feed.
- The fuel-inventory exercise must use inputs within the controls' limits. It now specifies its starting values.
- A zero exhaust inventory cannot give a defined doubling ratio. The comparison conditions exclude this case.

Numerical dissipation stays distinct from physical heat.
Inventory cuts stay distinct from extraction flow.
Equilibrium references stay distinct from calculated time histories.
Numerical verification stays distinct from experimental validation.

## Verification

Source review compares equations, links, identifiers, numerical conditions, and recorded evidence with the preceding revision.
Text assertions must keep the same physical and control requirements.
The final verification record will identify the executed tests, qualified source, and publication result.
