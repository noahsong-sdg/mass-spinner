# Stack modernization

17 November 2026. Working branch: `codex/stack-modernization`. The source audit is `STACK-AUDIT-20261117.md`. Changes are not yet merged or deployed. Qualification below distinguishes executed results from work still pending.

## What changed and why

| Problem | Technical cause / plain meaning | Fix and choice |
| --- | --- | --- |
| Aging runtime/compiler and stale build fallbacks | Tool entry points used different installations; upgrading the compiler also changed an imported API. A prepared machine could hide missing dependencies. | Pin Node 26.13.1 LTS and npm 11.20.0, use the TS 7 CLI with the explicit TS 6 compatibility API, remove personal `.tools/frontend` fallbacks. Keep the supported LTS bundled npm rather than introducing an unqualified independent npm-major upgrade. |
| Strict source typing missed important boundaries | `Array.isArray` widened readonly arrays, surface adapters used `any`, worker replies were trusted too early. Those paths could discard useful type information. | Typed surface state and geometry ownership, numeric arrays, unknown worker envelopes, contextual malformed-reply rejection; type-aware ESLint with zero warnings. No physical arithmetic changes. |
| Tests/tooling were not compiler checked | Test execution transpiles TypeScript without checking it. Passing assertions did not imply a well-typed harness. | Strict build/browser/release-tool checks and a strict test project. New tests are included by default. Existing harness debt is explicitly enumerated in `tooling-type-debt.json`, with a coverage regression test. Exempt tests still run. |
| No repeatable browser release gate | DOM tests cannot exercise real WebGL, downloads, browser workers or responsive layout. | Locked Playwright/Chromium and axe, desktop and phone tests, accepted-output assertions, screenshot/trace/performance evidence. Browser failure prevents publication of `verified-site`. Software rendering and reduced-motion control checks are labeled; native GPU/animation verification remains separate. |
| Deployment depended on manual build assembly | Dirty output and missing old lazy chunks could mix releases. A passing checkout did not identify deployed bytes. | Clean builds, per-file SHA-256 manifest, admitted CI artifact, pinned Wrangler, deliberate hashed-chunk retention, lifecycle/rollback tests and production smoke workflow. This preserves static Cloudflare hosting; a web-framework rewrite would not solve release identity. |
| Scientific environments and launchers were scattered | Frozen studies and active calculations lacked one maintained entry point. Installing a library did not prove it ran. | An active ownership index, committed uv/Python lock, Ruff, Snakemake source-addressed producer and independent cached-output admission. Keep historical Julia/native environments unchanged; record native image identity for new runs. |
| A custom thermal integrator needed an independent check | Conservation alone cannot establish temporal accuracy. | Compare nine live histories against SciPy Radau and BDF on the same finite-volume grids and material laws, with source hashes and fixed gates. This adds independent time integration without rewriting conservative browser kernels. |
| Blender was tied to an unsupported personal installation | Export metadata and mesh APIs changed across Blender versions. A new executable could silently alter component identity. | Digest/checksum-pinned Blender 5.2.4 LTS CPU workflow, numerical metadata preservation and 261-mesh semantic/geometry/material parity checks. Preserve frozen old source assets. |
| Graphics had no official validator or measured optimization | The assembly repeated identical buffers/meshes. Delivery cost was high even though individual components were simple. | Khronos validation and glTF Transform accessor/mesh deduplication; exact geometry streams, node hierarchy and metadata checked. No lossy quantization, material merging or decoder dependency. |
| Durable scenarios had separate language validators | TypeScript types disappear at runtime. A plausible Python or old scenario payload could have a different shape. | Shared versioned JSON Schema, Ajv/Python admission and identical old/current/malformed fixtures; keep chronological/physical domain checks. Validate at the data boundary, not every render frame. |
| Evidence and updates lacked one maintenance path | Large results accumulated in Git; pinned dependencies still age. | Checked immutable evidence packaging/retrieval and catalog format, weekly Dependabot and fail-closed advisory review. Do not delete historical results or add a second scheduler/storage system. |
| CI Actions used a deprecated Node runtime | Old immutable Action pins still targeted Node 20. GitHub was substituting another runtime. | Pin the current official checkout 7.0.1, upload-artifact 7.0.2 and download-artifact 8.0.2 commits, all Node 24; keep archive defaults and fail on digest mismatch. |
| Project reuse had no license | Third-party notices did not license original project code. | MIT, as chosen by the owner; third-party licenses remain in force. |

## Executed evidence

- [Active Python 3.15.2 environment, run 44211854088](https://github.com/noahsong-sdg/mass-spinner/actions/runs/44211854088): frozen lock sync, Ruff lint/format, active and public-diagnostic unit tests, two Snakemake invocations and nine thermal comparisons passed. NumPy 2.5.5 / SciPy 1.18.1 are recorded in the receipt.
- In that thermal case the finest-step maximum temperature difference was 0.716 K or less; halving the timestep approximately halved the error. Radau and BDF differed by at most 3.06e-6 K. This is a same-grid time-integration check, not spatial or experimental qualification. The 1% bound is normalized to the imposed 800 K initial temperature difference, as stated in the thermal protocol; it does not replace other convergence gates.
- [Blender CPU parity, run 44208872152](https://github.com/noahsong-sdg/mass-spinner/actions/runs/44208872152): all 261 selectable meshes retained their semantic geometry/material metadata, with a 1 µm coordinate tolerance; an actual render was produced.
- [Lossless glTF trial, run 44209899455](https://github.com/noahsong-sdg/mass-spinner/actions/runs/44209899455): 6,567,928 → 1,054,372 bytes (83.95% reduction), exact geometry streams and node metadata, zero Khronos errors. Warm NodeIO parsing improved from 11.56 to 2.48 ms median in that run. Those numbers are not browser cold-load time or GPU frame performance.
- A constrained compiler comparison measured TS 7 at 1.72 s / 346,400 KiB versus TS 6 at 9.57 s / 560,152 KiB on the same production typecheck. This is one workload, not a general speed guarantee.
- [Current FEniCSx reference, run 44214017313](https://github.com/noahsong-sdg/mass-spinner/actions/runs/44214017313): DOLFINx 0.11 passed all five unit tests and the unchanged field, refinement, torque and power gates on three grids. The independent scikit-fem field differences were at most 2.60e-11. The port changes the mesh-construction API, preserving the matched weak form and frozen 0.9 reference. This stationary synthetic comparison does not qualify the full coupled flow or an experiment.
- [Public evidence retrieval, run 44214017197](https://github.com/noahsong-sdg/mass-spinner/actions/runs/44214017197): the isolated setup retrieved the published catalog bundle and verified its hash and complete file inventory. The later offline step failed on one Ruff line-wrap violation, corrected separately. The catalog points to [the immutable evidence release](https://github.com/noahsong-sdg/mass-spinner/releases/tag/evidence-run-44211854088); no historical evidence was deleted.

## Acceptance still in progress

The full Node test/build passed on 219253c (run 44211854059), including required source/tool/test typechecks, lint, asset checks and release sealing. Its new browser gate caught invalid equation ARIA roles and a scrolling-table keyboard issue, now fixed with regression assertions. Deterministic browser controls use the app’s reduced-motion preference to avoid software-raster animation monopolizing the one-CPU runner. The final source still needs the complete gate. Advanced playground coverage must grow beyond module loading, and actual production deployment/rollback and native GPU checks remain separate from local browser lifecycle fixtures. Desktop/mobile software-renderer performance evidence must not be presented as a hardware baseline.

The qualified DOLFINx image has a binary-compatible Python/NumPy/PETSc stack independent of the Python 3.15 diagnostic environment. The frozen 0.9 implementation and results remain intact.

Historical test harnesses still contain recorded typing debt; no production source is exempt from strict checking. A bounded release-manifest project enables `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`, with compile-only regressions. Extending these flags across numerical indexing needs separate review.

One transitive picomatch advisory has no published patched version in the reviewed graph. The narrowly scoped temporary review expires 1 December 2026 and fails closed afterward; this is not a clean vulnerability bill of health. No physical tolerance was relaxed to pass an upgrade. The snapshot portability exception allows two machine epsilons only for named derived diagnostics, with exact trajectory/RNG state and regression rejection outside that bound.

## Review and rollout

Keep the existing Vite/Three.js/Cloudflare architecture: there is no demonstrated need for a backend, React rewrite, CAD authority claim or WebGPU migration. The audit's CAD/WASM/framework alternatives remain conditional decisions rather than missing packages.

This branch spans several reviewable changes and must not be presented as a single under-700-line PR. Review in order: compiler/static contracts; release/browser gates; scientific environment and evidence; Blender/assets. Toolchain checks establish implementation and reproducibility properties, not experimental accuracy of Marathon's device.
